# Sprint 11 evaluation rehearsal

Open the Evaluation rehearsal entry in the workspace, or `/evaluate` on the reviewed deployment. The route uses synthetic study records; it does not load your real project, account, cloud workspace or existing review/sign-off history.

A researcher-assigned allocation slot selects one of four predefined scenario/display orders. Slots 0–3 form a balanced block; this is not a hidden randomization service. Select individual or PO–developer pair, read the local-rehearsal consent and start. Each rule takes a judgement, record IDs as evidence and an explanation. Submitting freezes the review and hides the specification for the independent prediction check. The second assignment uses the other scenario and display. No correctness feedback is given between trials.

After both trials, JSON and CSV exports contain pseudonymous session identity, scenario hashes/revisions, order, condition, timing, evidence, reasoning and predictions. Nothing is sent automatically. Typed free text is included as entered; keep identities and confidential information out of it. The scorer is a separate offline researcher tool and receives a private, version-bound reference package; participant exports never contain the key or scores.

A reload during a timed trial requires an explicit restart. Its interrupted record is retained as abandoned, and the exported restart count makes the limitation visible. Completed records can be restored without a restart. A failed save keeps the previous bytes and allows an explicit retry. Another-tab changes stop stale submission/export. Unreadable or stale saved bytes can be downloaded unchanged; they are never silently replaced.

Withdrawal asks for confirmation and clears only the evaluation storage key. It cannot erase copies already downloaded or shared; their holder controls those copies. Browser-local storage is not a cross-device research archive. CI test artifacts use synthetic data and request 90-day retention; scenario definitions and executable tests remain in Git history.

This is a rehearsal ready for engineering review and supervised pilot validation. It is not authorization to recruit participants, an approved consent protocol, proof that visual presentation is more effective, or an automated coding-agent run. Publication requires its own owner decision after the reviewable candidate is ready. The thesis comparison is in `THESIS_ALIGNMENT_REVIEW.md`.
