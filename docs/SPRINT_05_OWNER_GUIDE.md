# How to evaluate Sprint 05

1. Open https://visual-sdd-platform.vercel.app.
2. Create/approve a Specification with at least one requirement and acceptance criterion.
3. In **SDD Canvas → Technical Plan**, create a plan and fill technical architecture and risks; approve it.
4. In **Tasks**, create an actionable Task linked to that requirement and acceptance criterion. Approve the task breakdown.
5. Return to **Specification** and change the criterion text or requirement statement. Do not assume prior approvals remain valid.
6. Open **SDD Canvas → Change impact**. Select the changed item. Inspect the before/after comparison, direct task link, potential review list and stale Plan/Task/Implement gates.
7. Export the Markdown impact report. Review the existing plan and task definitions manually before creating a new plan against the revised approved Specification.

For older plans without a snapshot, the UI should display **Legacy plan — baseline missing**. This is deliberate: the software must not invent a prior state.

Google login and persistent My Projects remain unchanged. Plan snapshots and Tasks are browser-only for now. No Codex run or code release is performed by this feature.
